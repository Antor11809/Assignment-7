
# 🛒 BazarDor — বাজার দর

BazarDor is a modern web application that helps users explore daily market prices of essential products in Bangladesh.

## Features

- Responsive homepage with product categories
- Latest product prices
- Dynamic product details pages
- Market-wise product price comparison
- User authentication with Better Auth
- Email and password signup and login
- Google and GitHub social authentication
- Protected product details and profile routes
- User profile management
- Custom loading and 404 pages
- Toast notifications

## Technologies Used

- Next.js 16
- React.js
- Tailwind CSS
- DaisyUI
- Better Auth
- MongoDB
- React Hot Toast

## Installation

1. Clone the repository.
2. Install dependencies:

   npm install

3. Configure environment variables in `.env.local`.

4. Start the development server:

   npm run dev

5. Open http://localhost:3000
